# Мой день — приложение для Android

Планировщик задач и событий без рекламы. В приложении нет доступа к интернету: все записи хранятся только на телефоне.

## Как получить .apk без установки программ на компьютер (через GitHub)

1. Зарегистрируйтесь на github.com (бесплатно) и создайте новый репозиторий: «New repository», название любое.
2. Распакуйте этот архив. В репозитории нажмите «uploading an existing file» и перетащите ВСЁ содержимое папки moy-den-android, включая скрытую папку .github. Нажмите «Commit changes».
3. Откройте вкладку «Actions». Сборка запустится сама и займёт 3–5 минут. Если не запустилась, выберите «Build APK» и нажмите «Run workflow».
4. Когда сборка станет зелёной, откройте её и внизу в разделе «Artifacts» скачайте moy-den-apk. Внутри файл app-debug.apk.
5. Перенесите app-debug.apk на телефон и откройте его. Android попросит разрешить установку из этого источника: разрешите.

## Как собрать в Android Studio

Откройте папку проекта в Android Studio и выберите Build → Build APK(s). Нужен Android 10 или новее.

## Перенос записей с веб-версии

Записи в веб-версии и в приложении хранятся отдельно. В веб-версии откройте Настройки → «Сохранить в файл», затем в приложении Настройки → «Загрузить из файла».
