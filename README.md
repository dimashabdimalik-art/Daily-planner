# Ежедневник

Простой ежедневник без рекламы: задачи, расписание и календарь. Работает без интернета, все записи хранятся только на вашем телефоне.

## Что умеет

- Задачи на сегодня: напишите слово, нажмите «+», выполнили — поставьте галочку.
- Календарь с событиями по времени, повтором (каждый день, по будням, раз в неделю) и цветными метками.
- Цели на месяц и задачи на каждый день месяца с общим прогрессом.
- Перенос невыполненных задач на сегодня.
- Резервная копия записей в файл (папка «Загрузки»).
- Ежедневное напоминание в выбранное время (в приложении).
- Свайп по календарю листает месяцы, кнопка «Назад» закрывает окна.
- Светлая и тёмная темы, выбор цвета и размера текста, фраза дня.

## Приватность

Нет рекламы, регистрации и слежки. У приложения нет доступа к интернету, все записи хранятся только на устройстве.

## Требования

Android 10 или новее.

## Как получить .apk

1. Откройте вкладку **Actions** этого репозитория. Сборка запускается сама после загрузки файлов (3–5 минут). Если не запустилась, выберите «Build APK» и нажмите «Run workflow».
2. Когда сборка станет зелёной, откройте её и скачайте **moy-den-apk** из раздела «Artifacts». Внутри файл app-debug.apk.
3. Перенесите файл на телефон и откройте его. Android попросит разрешить установку из этого источника.

Другой способ: откройте проект в Android Studio и выберите Build → Build APK(s).

## Перенос записей из веб-версии

Записи в веб-версии и в приложении хранятся отдельно. В веб-версии: Настройки → «Сохранить в файл». В приложении: Настройки → «Загрузить из файла».

## Безопасность

- У приложения нет разрешения на интернет, сетевые запросы заблокированы, переходы по ссылкам запрещены.
- Вход по замку телефона (PIN, рисунок, отпечаток): Настройки → «Защита». При включении содержимое скрывается в списке недавних приложений и на снимках экрана.
- Автоматическое резервное копирование Android отключено, записи остаются только на устройстве.
- Данные из файла копии проверяются перед загрузкой: лишние и некорректные поля отбрасываются.
- Установочный файл подписан отладочным ключом. Для личного использования этого достаточно.
